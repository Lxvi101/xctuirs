# Security

xctuirs runs Apple's command-line tools on your machine with your existing signing setup. It doesn't make network requests of its own and doesn't store credentials. Run history and preferences are kept under `~/Library/Application Support/xctui/`.

If you find a security problem, please report it privately through [GitHub's private vulnerability reporting](https://github.com/Lxvi101/xctuirs/security/advisories/new) instead of opening a public issue.
